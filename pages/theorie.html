Signed Distance Functions

Grundidee

Eine Signed Distance Function (SDF) beschreibt die Geometrie eines Objekts über eine mathematische Funktion. Anstatt die Oberfläche durch Vertices und Dreiecke darzustellen, liefert die Funktion für jeden Punkt im Raum den Abstand zur nächstgelegenen Oberfläche.

Der Begriff signed bedeutet, dass dieser Abstand mit einem Vorzeichen versehen wird. Dadurch lässt sich nicht nur bestimmen, wie weit ein Punkt von einem Objekt entfernt ist, sondern auch, ob er sich innerhalb oder außerhalb des Objekts befindet.

Für einen beliebigen Punkt \(p\) gilt:

\(f(p) < 0\): Der Punkt befindet sich innerhalb des Objekts.

\(f(p) = 0\): Der Punkt liegt auf der Oberfläche.

\(f(p) > 0\): Der Punkt befindet sich außerhalb des Objekts.

Die Oberfläche eines Objekts entspricht somit genau der Menge aller Punkte, für die die Funktion den Wert Null annimmt.

Formale Definition

Allgemein kann eine Signed Distance Function als Funktion

\[ f:\mathbb R^3 \rightarrow \mathbb R \]

aufgefasst werden, die jedem Punkt im dreidimensionalen Raum einen signierten Abstand zur nächstgelegenen Oberfläche zuordnet.

Da eine SDF nicht nur Informationen über die Oberfläche, sondern über den gesamten Raum enthält, eignet sie sich besonders gut für geometrische Abfragen und Verfahren wie Ray Marching, die direkt auf diesen Distanzinformationen aufbauen (Friedrich 2025b; Wong 2016).

Die Kugel als Beispiel

Die Idee einer Signed Distance Function lässt sich gut anhand einer Kugel veranschaulichen. Angenommen, die Kugel besitzt den Radius \(r\) und ihr Mittelpunkt befindet sich im Ursprung des Koordinatensystems.

Für einen beliebigen Punkt \(\mathbf p\) im Raum kann zunächst dessen Abstand zum Ursprung berechnet werden. Liegt der Punkt genau auf der Oberfläche der Kugel, entspricht dieser Abstand dem Radius \(r\). Befindet sich der Punkt außerhalb der Kugel, ist der Abstand größer als \(r\), innerhalb der Kugel entsprechend kleiner.

Die Signed Distance Function einer Kugel ergibt sich daher zu

\[ f(\mathbf p)=||\mathbf p||-r \]

Der Ausdruck \(||\mathbf p||\) beschreibt den euklidischen Abstand des Punktes \(\mathbf p\) zum Ursprung. Durch das Subtrahieren des Radius erhält man direkt den Abstand zur Kugeloberfläche.

Diese Formel gilt für eine Kugel mit Mittelpunkt im Ursprung. Für eine Kugel mit einem beliebigen Mittelpunkt \(\mathbf c\) lässt sich die Funktion entsprechend anpassen: \[ f(\mathbf{p}) = \|\mathbf{p} - \mathbf{c}\| - r \]

Primitive Formen und Operationen

Die Kugel stellt das einfachste Beispiel einer Signed Distance Function dar. Das zugrunde liegende Konzept lässt sich jedoch auf viele weitere geometrische Grundkörper übertragen. Für jede Form existiert eine Funktion, die für einen beliebigen Punkt im Raum den Abstand zur nächstgelegenen Oberfläche berechnet.

Zu den häufig verwendeten Primitiven gehören unter anderem Kugeln, Ebenen, Quader, Zylinder und Torusse. Obwohl sich die zugrunde liegenden Formeln teilweise deutlich unterscheiden, verfolgen sie alle dasselbe Ziel: Die Geometrie eines Objekts wird durch eine mathematische Beschreibung seiner Oberfläche definiert.

Primitive SDFs bilden die Grundlage für die Modellierung komplexerer Szenen. Ähnlich wie bei der klassischen 3D-Modellierung werden zunächst einfache Grundformen definiert, aus denen anschließend komplexe Strukturen aufgebaut werden können.

Ray Marching

Grundidee

Nachdem die Geometrie einer Szene durch Signed Distance Functions beschrieben wurde, stellt sich die Frage, wie diese dargestellt werden kann. Im Gegensatz zu polygonalen Netzen existieren keine expliziten Dreiecke, die gerendert oder auf Schnittpunkte getestet werden können. Stattdessen liegt lediglich eine mathematische Beschreibung der Szene vor.

Um die Oberfläche eines Objekts zu finden, wird für jedes Pixel ein Strahl von der Kamera in die Szene gesendet. Die Aufgabe besteht nun darin, entlang dieses Strahls den Punkt zu bestimmen, an dem eine Oberfläche getroffen wird.

Nutzung von Signed Distance Functions

Der entscheidende Vorteil einer Signed Distance Function besteht darin, dass sie nicht nur beschreibt, ob sich ein Punkt innerhalb oder außerhalb eines Objekts befindet, sondern zusätzlich den Abstand zur nächstgelegenen Oberfläche liefert.

Betrachtet man einen beliebigen Punkt entlang eines Strahls, so kann die Signed Distance Function direkt ausgewertet werden. Das Ergebnis gibt an, wie weit die nächste Oberfläche entfernt ist.

Diese Information kann genutzt werden, um sich entlang des Strahls schrittweise auf die Oberfläche zuzubewegen. Anstatt feste Schrittweiten zu verwenden, wird die aktuell berechnete Distanz als neue Schrittweite gewählt. Dadurch kann sich der Strahl in leeren Bereichen der Szene schnell fortbewegen, während die Schritte in der Nähe einer Oberfläche automatisch kleiner werden.

Der Ray-Marching-Algorithmus

Der Algorithmus beginnt am Ursprung des Strahls, welcher sich typischerweise an der Kameraposition befindet. Anschließend wird die Signed Distance Function am aktuellen Punkt ausgewertet. Der zurückgegebene Distanzwert bestimmt, wie weit sich der Strahl entlang seiner Richtung bewegen kann.

Dieser Vorgang wird wiederholt, bis die Distanz zur nächsten Oberfläche ausreichend klein wird. In diesem Fall wird davon ausgegangen, dass die Oberfläche erreicht wurde.

Der grundlegende Ablauf lässt sich wie folgt zusammenfassen:

  1. Erzeuge einen Strahl von der Kamera in die Szene.
  2. Werte die Signed Distance Function am aktuellen Punkt aus.
  3. Bewege den Strahl um die berechnete Distanz entlang seiner Richtung.
  4. Wiederhole die Schritte 2 und 3.
  5. Breche ab, sobald die Oberfläche erreicht wurde oder der Strahl die Szene verlässt.

Die folgende Visualisierung verdeutlicht dieses Vorgehen. Die Schrittweite entspricht dabei jeweils dem Abstand zur nächstgelegenen Oberfläche. Mit jeder Iteration nähert sich der Strahl dem Objekt an, bis schließlich ein Schnittpunkt gefunden wird.

  • Animierte Schritte
  • Parametrische Steuerung

Das hier beschriebene Verfahren wird häufig als Ray Marching bezeichnet. Genauer handelt es sich aber um eine spezielle Form des Ray Marching, die als Sphere Tracing bekannt ist. Sie wurde 1996 von John C. Hart vorgestellt und nutzt die Distanzinformationen einer Signed Distance Function, um die Schrittweite adaptiv anzupassen (Hart 1996).

Abbruchbedingungen

Da eine Oberfläche in der Praxis selten exakt getroffen wird, wird ein kleiner Schwellwert \(\varepsilon\) definiert. Unterschreitet die berechnete Distanz diesen Wert, gilt die Oberfläche als erreicht.

Zusätzlich werden maximale Grenzen für die Anzahl der Iterationen und die zurückgelegte Distanz festgelegt. Dadurch wird verhindert, dass ein Strahl unbegrenzt weiterläuft, falls keine Oberfläche getroffen wird.

Diese Abbruchbedingungen stellen sicher, dass der Algorithmus auch für komplexe Szenen in einer endlichen Anzahl von Schritten terminiert.

Shading und Beleuchtung

Nachdem durch Ray Marching ein Schnittpunkt mit der Oberfläche bestimmt wurde, kann die Farbe des entsprechenden Pixels berechnet werden. Die Position des Schnittpunkts allein reicht hierfür jedoch nicht aus. Um Beleuchtungseffekte darstellen zu können, wird zusätzlich die Orientierung der Oberfläche benötigt.

Oberflächennormalen

Bei polygonalen Netzen können Oberflächennormalen direkt aus den Dreiecken eines Modells berechnet werden. Da Signed Distance Functions keine explizite Geometrie besitzen, muss diese Information auf anderem Weg gewonnen werden.

Eine SDF beschreibt den Raum durch eine mathematische Funktion. Die Oberflächennormale ergibt sich dabei aus dem Gradienten dieser Funktion und zeigt in die Richtung der stärksten Änderung des Distanzwertes. Mathematisch lässt sich die Normale als normierter Gradient ausdrücken:

\[ \mathbf n = \frac{\nabla f}{||\nabla f||} \]

In der Praxis wird der Gradient meist numerisch approximiert, indem die Signed Distance Function an mehreren benachbarten Punkten ausgewertet wird. Auf diese Weise kann für jeden Oberflächenpunkt eine Normale bestimmt werden, die anschließend für die Beleuchtungsberechnung verwendet wird.

\[ \mathbf n \approx \begin{bmatrix} f(x+\varepsilon,y,z)-f(x-\varepsilon,y,z) \\ f(x,y+\varepsilon,z)-f(x,y-\varepsilon,z) \\ f(x,y,z+\varepsilon)-f(x,y,z-\varepsilon) \end{bmatrix} \]

Der resultierende Vektor wird anschließend normalisiert, da für die Beleuchtung nur die Richtung der Normalen relevant ist (Friedrich 2025b; Quilez, o. J.-c).

Phong-Beleuchtungsmodell

Nachdem die Oberflächennormale bestimmt wurde, kann die Beleuchtung des Oberflächenpunkts berechnet werden. In unserer Implementierung verwenden wir hierfür das Phong Reflection Model, das sich aus drei Komponenten zusammensetzt:

  • Ambient Lighting
  • Diffuse Lighting
  • Specular Lighting

Der Ambient-Anteil beschreibt eine konstante Grundbeleuchtung der Szene. Die diffuse Komponente modelliert die direkte Beleuchtung durch eine Lichtquelle und hängt vom Winkel zwischen Oberflächennormale und Lichtvektor ab. Der spekulare Anteil erzeugt Glanzlichter und simuliert reflektierende Oberflächen.

Die diffuse Beleuchtung wird häufig mithilfe des Lambert-Modells berechnet. Die Intensität ergibt sich aus dem Skalarprodukt zwischen Oberflächennormale (n) und Lichtvektor (l):

\[ I_d = \max(0,\mathbf n \cdot \mathbf l) \]

Flächen, die direkt zur Lichtquelle zeigen, werden dadurch stärker beleuchtet als Flächen, die in einem flachen Winkel zur Lichtquelle stehen.

Durch die Kombination von Ambient-, Diffuse- und Specular-Komponente entsteht ein deutlich realistischeres Erscheinungsbild der Szene. Die zuvor berechneten Oberflächennormalen spielen dabei eine zentrale Rolle, da sie die Grundlage für sämtliche Beleuchtungsberechnungen bilden (Friedrich 2025a).

Schatten

Das Beleuchtungsmodell allein entscheidet nur, wie stark ein Punkt beleuchtet würde, wenn ihn das Licht erreicht. Es prüft jedoch nicht automatisch, ob sich zwischen dem Punkt und der Lichtquelle ein anderes Objekt befindet. Im Gegensatz zum vereinfachten lokalen Beleuchtungsmodell der Vorlesung (Friedrich 2025a) lassen sich beim SDF-basierten Ray Marching Schatten direkt ohne separate Shadow Maps realisieren.

Für Schatten wird daher ein zusätzlicher Strahl verwendet. Nachdem durch Ray Marching ein Oberflächenpunkt gefunden wurde, wird von diesem Punkt aus ein zweiter Strahl in Richtung der Lichtquelle gesendet. Dieser sogenannte Shadow Ray überprüft, ob auf dem Weg zur Lichtquelle ein anderes Objekt getroffen wird.

Falls der Shadow Ray vor Erreichen der Lichtquelle auf eine Oberfläche trifft, liegt der ursprüngliche Punkt im Schatten. Andernfalls wird er normal beleuchtet.

Die Schattenberechnung funktioniert damit ähnlich wie beim klassischen Ray Tracing. Der Unterschied liegt darin, dass auch dieser zusätzliche Strahl nicht gegen Dreiecke getestet wird, sondern wieder mithilfe der Signed Distance Function durch die Szene gemarcht wird.

Auf diese Weise können Schatten direkt in das SDF-basierte Rendering integriert werden, ohne eine separate Schattenkarte (Shadow Map) oder explizite Geometrie zu benötigen (Quilez, o. J.-d).

Ambient Occlusion

Ambient Occlusion (AO) ist eine Technik, die zur Verbesserung der Tiefenwahrnehmung und Realismus in 3D-Szenen eingesetzt wird.

Die Grundidee besteht darin, abzuschätzen, wie stark ein Punkt auf einer Oberfläche von seiner Umgebung verdeckt wird. Befindet sich ein Punkt in einer offenen Region, kann Umgebungslicht ihn nahezu ungehindert erreichen. Liegt er dagegen in einer Ecke, einer Vertiefung oder nahe an anderen Objekten, wird ein Teil dieses Lichts blockiert und die Stelle erscheint dunkler.

Bei SDF-basiertem Rendering lässt sich Ambient Occlusion vergleichsweise einfach berechnen. Ausgehend vom Oberflächenpunkt werden entlang der Oberflächennormalen mehrere Punkte in kleinen Abständen \(h_i\) abgetastet. Für jeden dieser Punkte wird die Signed Distance Function ausgewertet und ein Distanzwert \(d_i\) bestimmt.

In einer offenen Umgebung entspricht die von der SDF zurückgegebene Distanz ungefähr dem gewählten Abtastabstand (\(d_i \approx h_i\)). Dies deutet darauf hin, dass sich entlang der Normalen keine weitere Geometrie in unmittelbarer Nähe befindet und der Punkt nur gering verdeckt wird. Befinden sich dagegen andere Oberflächen in der Nähe, fallen die gemessenen Distanzwerte kleiner aus als erwartet (\(d_i < h_i\)). Dies weist auf eine stärkere Verdeckung hin und reduziert den Ambient-Occlusion-Wert.

Auf diese Weise lässt sich abschätzen, wie stark die Umgebung eines Punktes das einfallende Umgebungslicht blockiert. Bereiche mit hoher Verdeckung erscheinen dunkler, während offene Bereiche heller dargestellt werden.

Im Gegensatz zu klassischen Schatten hängt Ambient Occlusion also nicht von einer bestimmten Lichtquelle ab. Stattdessen beschreibt sie die lokale geometrische Umgebung eines Punktes und erzeugt dadurch zusätzliche Tiefen- und Kontaktinformationen (Quilez, o. J.-a).
